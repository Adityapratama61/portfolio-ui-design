# Portfolio Website: UI Design

A personal portfolio website design built in Figma, with a clickable prototype. It presents my projects, experience, and contact details in a clean, dark, single-column layout.

> **Status:** Work in progress. Next step is turning this design into a coded website with React and Tailwind CSS.

## Preview

![Home page overview](assets/home-overview.png)

**Live prototype:** [Open in Figma](YOUR_FIGMA_PROTOTYPE_LINK)

## Pages

| Page | Description |
|---|---|
| Home | Profile, education, certificates, and tech stack |
| Projects | Grid of project cards |
| Project Detail | Role, team, features, stack, and links |
| Experience | Work experience list with expandable items |
| Experience Detail | Focus areas and what I worked on |
| Contact | Email, LinkedIn, and GitHub |

## Design Highlights

- Dark theme with thin borders and hatched section dividers
- Monospace tags and script-style section titles
- Reusable components: navbar, project card, list row, tag, and accordion
- Auto Layout throughout, so content resizes cleanly
- Prototype interactions: page navigation, expandable accordions, and a settings dropdown

## Tools

- **Figma**: UI design, components, variants, and prototyping
- **Lucide / Iconify**: icons
